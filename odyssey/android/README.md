# ODYSSEY — Android Studio build

Open **this `android/` folder** directly in Android Studio
(`File → Open…` → pick the `android` folder). First sync downloads
two small libraries (AndroidX + WebView) — after that the build is
completely offline and needs no setup beyond the IDE itself.

## Build & install

| What | How |
|---|---|
| Quick APK | `Build → Build App Bundle(s) / APK(s) → Build APK(s)` — the APK lands in `android/app/build/outputs/apk/debug/` |
| On a phone | enable *Developer options → USB debugging*, plug in, press **Run ▶** in Android Studio |
| Release APK | `Build → Generate Signed App Bundle / APK` (a debug-signed release APK is pre-configured; add your own keystore before publishing) |

## What the app is

A single-activity, zero-network wrapper around the exact game in the
parent folder:

- the game files are copied into `app/src/main/assets/` and served to
  a fullscreen WebView via `WebViewAssetLoader`
  (`https://appassets.androidplatform.net/assets/`), so ES modules,
  `localStorage` saves and the self-hosted fonts all work;
- **no INTERNET permission** — the APK cannot phone home;
- immersive fullscreen, landscape, back button = advance dialogue
  (double-press back to quit);
- launcher icon is the game's own pottery ship, adaptive on Android 8+.

## Updating the game inside the app

The assets are a **copy**, not a link. After changing any game file,
re-copy it (from the folder that contains this `android/` directory):

```
cp index.html styles.css android/app/src/main/assets/
cp -r js scenes fonts android/app/src/main/assets/
```

then rebuild. (On Windows, use `Copy-Item` in PowerShell the same way.)

## Requirements

- Android Studio (Hedgehog or newer recommended)
- Android SDK Platform 34 (the IDE offers to install it on first sync)
- A device or emulator on Android 7.0+ (minSdk 24)

The Gradle wrapper is generated by Android Studio automatically on
first open (`File → Sync Project with Gradle Files`); this keeps the
repo free of a ~100MB binary jar.
